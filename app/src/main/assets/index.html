YouTube Data API v3 key
Needed to auto-fetch tutorial videos. Stored only on this device.
Get a key from Google Cloud Console → enable YouTube Data API v3 → create an API key. In the source code the key can also be baked in as a default: edit DEFAULT_API_KEY at the top of the script in app/src/main/assets/index.html (or build.gradle → buildConfigField).
About
FitTrack keeps every workout on this device (localStorage). Video search uses the YouTube Data API with videoEmbeddable=true and videoLicense=creativeCommon; playback is controlled by the YouTube IFrame Player API so the video pauses the moment the timer hits 00:00.
